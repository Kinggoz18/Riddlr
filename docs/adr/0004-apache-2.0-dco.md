# Apache-2.0 and DCO

Riddlr is Apache-2.0 with a Developer Certificate of Origin instead of a CLA.
The Node dependency allowlist is permissive licenses only. AGPL services such as
SearXNG run as separate containers, never as npm packages.

**Status:** accepted; the DCO part is superseded (2026-09-30)

## Update (2026-09-30)

DCO sign-off is no longer required. Commits are plain Conventional Commits with
no `Signed-off-by` or `Co-authored-by` trailers. Riddlr stays Apache-2.0, and
contributions are licensed under Apache-2.0.
