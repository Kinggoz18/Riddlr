# Typed signal policies

Application code maps catalyst kinds onto eight typed signals and applies proof
requirements before a row is persisted. The model cannot choose the type.
Operators see the type on Signals. Perp stress is always a market observation.
Token unlock is always labeled anticipated. Tally is not shipped; Snapshot
proposal evidence validates governance. Unlock calendar evidence is source
family `calendar`; without it an unlock persists as anticipated and is not
notify-eligible.

**Status:** accepted
