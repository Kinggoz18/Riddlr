# Event clustering and independence

Evidence in a scan is clustered by matching claim fingerprints, then by shared
canonical subjects plus character-shingle similarity. Distinct propositions
about the same asset stay separate. Exact URL or content-hash copies, native
references, and near-duplicates above the shingle threshold are derived reprints.
Independent origin count is not reprint count and is not hostname count on a
social platform. Market observations are extracted from source text or adapter
payloads with a source id; they are not invented metrics. Remainder that does not
fit the event cap is deferred, not discarded.
