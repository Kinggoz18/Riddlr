# SEC EDGAR

Riddlr polls EDGAR only when you add it. Filings are official evidence for
Equities agents and EFTS keyword hits for Crypto agents.

Sources → **Add source** → **Configure SEC EDGAR**. Contact email required.
User-Agent is `Riddlr/<version> <email>`.

See [integrations/edgar.md](../integrations/edgar.md). Company IR RSS feeds use
the existing feeds adapter; attach them to the Equities agent.
