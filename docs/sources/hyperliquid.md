# Hyperliquid

Riddlr polls Hyperliquid only when you add it. It is an observation source for
perpetual funding, open interest, and mark price. It does not replace CoinGecko
spot.

Sources → **Add source** → **Configure Hyperliquid**. No API key. One poll
returns every perp; only watchlist, portfolio, and pinned subjects are stored.
Pin `hyperliquid:COIN` on Health for an unmapped coin.

See [integrations/hyperliquid.md](../integrations/hyperliquid.md).
