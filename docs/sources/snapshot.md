# Snapshot

Riddlr polls Snapshot only when you add it. It is an evidence source for
governance proposals. It does not replace CoinGecko spot. Tally is not shipped.

Sources → **Add source** → **Configure Snapshot**. No API key. Pin space ids
such as `grovefinance.eth`. Aave, Uniswap, Compound, and ENS map from the
watchlist automatically.

See [integrations/snapshot.md](../integrations/snapshot.md).
