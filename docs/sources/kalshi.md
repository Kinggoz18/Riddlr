# Kalshi

Riddlr polls Kalshi only when you add it. It is an observation source for
US-regulated prediction-market odds. It does not replace CoinGecko spot.

Sources → **Add source** → **Configure Kalshi**. No API key. Pin series tickers
such as `KXCPI`. Do not fetch the unfiltered series list. Pin `kalshi:TICKER`
on Health for a series or market that is not on the form.

See [integrations/kalshi.md](../integrations/kalshi.md).
