# DefiLlama

Riddlr polls DefiLlama only when you add it. It is observation and hacks
evidence, not a market-data quote source, and it does not replace CoinGecko.

Sources → **Add source** → **Configure DefiLlama**. Terms are personal and
non-commercial. Results stay in this operator database.

Pinned chains use DefiLlama chain names (`Ethereum`, not `eth`). Extra protocol
slugs supplement watchlist mapping. Protocol TVL is stored as the latest point
every 15 minutes. Hacks are hourly.

See [integrations/defillama.md](../integrations/defillama.md).
