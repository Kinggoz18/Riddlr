# Polymarket

Riddlr polls Polymarket only when you add it. It is an observation source for
YES odds. It does not replace CoinGecko spot.

Sources → **Add source** → **Configure Polymarket**. No API key. Pin market
slugs such as `fed-rate-hike-in-2026`. Pin `polymarket:slug` on Health for a
market that is not on the form. Closed markets are unsubscribed.

See [integrations/polymarket.md](../integrations/polymarket.md).
